## Inspect before copying

The gallery filters countries/regions and searches stored names/codes. A detail panel shows the full flag, whole/cropped frames, source facts, copy recipes and downloads. Choose a variant explicitly where needed. The standalone builder previews the same native element and offers module, element, framework, iframe, image and data-URI recipes.

## Save the selected view

SVG retains vector text; PNG renders the selected size. JSON retains the drawing's metadata. The browser creates these files when asked. A copied link carries documented choices and can be opened in the demo; do not infer political status from a gallery grouping or a quiz answer. The seeded quiz uses the same stored names and drawings and is separate from the SDK's loading API.
