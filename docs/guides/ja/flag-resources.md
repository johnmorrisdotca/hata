## 固定の絵を選ぶ

これはpackage.jsonの公開の入口から作る一覧です。コードの数と、枠用の絵や別の旗を含むモジュールの数は別です。既定と名前付きのsvgは同じSVGの文章です。元の資料・ライセンス・寸法を保ちます。

```ts
import japan, { svg } from "@johnmorrisdotca/hata/flags/jp";
console.log(japan===svg,svg.startsWith("<svg"));
```
