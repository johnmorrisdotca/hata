## 説明のサイトを使う

このブランチは版を変えず、リリースしません。既存の import と元の SVG のワイルドカードを保ち、名前付きの絵も同じモジュールです。API の索引は元のアンカーを保ち、詳しいページへ進めます。端末の検索と Markdown・llms は外部のサービスを必要としません。元の1.x の[変更履歴](../../../CHANGELOG.md)を保ちます。

## 旗のアイコン集から移る

Hata の import は本来の比率の SVG の文章で、CSS のクラスや一律の正方形ではありません。全体、枠用の絵、明確な切り抜きのどれが必要かを選びます。画像すべてにパッケージのライセンスを当てず、作者とライセンスを保ちます。名前の言語、状態、別の旗も明確にします。CDN の主な版の固定と依存関係の固定は別です。意図して更新するときは素材と JavaScript の版をそろえます。
