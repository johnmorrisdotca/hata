## コピーする前に確認する

一覧で国・地域を絞り、保存した名前やコードで探せます。詳細には旗の全体、枠ごとの全体と切り抜き、資料、コピーの例、保存があります。必要な別の旗は明確に選びます。作成画面は同じ標準の要素を表示し、モジュール・要素・フレームワーク・iframe・画像・data URI の例を示します。

## 選んだ表示を保存する

SVG はベクトルの文章、PNG は指定した大きさの絵、JSON は絵の記録を保ちます。頼んだときにブラウザーがファイルを作ります。コピーしたリンクは説明した選択を保ち、デモで開けます。一覧の区分やクイズから政治上の状態を推測しません。固定した種のクイズは保存した名前と絵を使い、SDK の読み込み API とは別です。
